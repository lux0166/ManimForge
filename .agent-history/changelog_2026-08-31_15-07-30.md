# Technical Changelog — 2026-08-31 15:07:30

## 1. Summary of Changes
- **Native Manim Engine (`src-tauri/src/manim_engine.rs`)**:
  - Asynchronously spawns `python -m manim` with stderr/stdout regex parsing.
  - Emits real-time progress events (`manim://progress`) with percentage, current animation phase, and error tracebacks.
  - Automatically discovers rendered `.mp4` files in the project's `media/` directory and converts them to Tauri asset URLs.
- **Autonomous CLI Runner (`src-tauri/src/cli_runner.rs`)**:
  - Multi-agent subprocess dispatcher for `agy`, `opencode`, `cline`, `claude`, `cursor`, `codex`, `ollama`.
  - Parses outputs into structured stream chunks (`thought`, `tool`, `text`, `done`).
  - Native Windows process flag handling (`CREATE_NO_WINDOW`).
- **Project File Manager (`src-tauri/src/project_manager.rs`)**:
  - File persistence in `Documents/ManimForge/Projects/` with `project.json` metadata and `scene.py`.
  - Regex AST parameter parser (`parse_scene_parameters`) to extract hyperparameter tokens for `ParameterInspector`.
- **Frontend Reactive Bridge (`src/lib/tauri-bridge.ts` & `src/App.tsx`)**:
  - Integrated live project switching, loading, and saving from disk.
  - Wired live `onRenderProgress` and `onAgentStream` listeners.
  - Connected `PromptBar` to real agent execution and `PreviewPanel` to live rendering.
